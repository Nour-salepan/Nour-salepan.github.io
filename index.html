background

What transfers from data analysis

Before security I worked as a data analyst, and the overlap is larger than it looks. A SOC analyst triaging alerts and an analyst auditing a dataset are doing the same thing: separating the signal that matters from the noise that doesn't.

  • Anomaly detection. In a marketing dataset I flagged an 89.7x return figure as implausible against a 2.5–4.7x peer range — it was a units error inflating the headline number by 73%. That reflex, distrusting the outlier that looks too good, is exactly what alert triage demands.
  • Evidence discipline. Every number cross-checked two independent ways before it reached a stakeholder. Security findings need the same: verify manually before you escalate.
  • Writing for non-technical readers. An analysis nobody acts on is wasted, and so is an incident report nobody understands.
  • Querying and scripting. SQL, Python and Bash — the same tools used to search logs and automate repetitive investigation.
